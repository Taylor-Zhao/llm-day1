# Day42 90 秒项目自我介绍（面试版）

你好，我最近做了一个 LLM 后端工程化项目，目标是把“模型能力验证”和“服务上线治理”串成完整闭环。

前半部分我做了 Day29 到 Day35：先基于 LoRA/QLoRA 走通小规模微调，再用固定评测集比较微调前后效果，同时对推理模式做了性能对比，最后把训练、效果、速度三块结果汇总成实验报告。

后半部分我做了 Day36 到 Day38：把推理能力封装成统一 FastAPI 服务，并补齐了工程化能力，包括 API Key 鉴权、滑动窗口限流、统一错误码、指数退避重试，以及请求/延迟/token/失败原因监控。

现在我又推进了 Day39 到 Day41：输出了可公网访问部署 runbook、3-5 分钟演示脚本和技术决策文档，用于对外展示和面试表达。

这个项目对我最大的价值是，我不只是“调用模型”，而是能从数据、训练、评测、推理优化到服务治理全链路交付，并且每一步都有可复现脚本和文档支撑。
